## 双人对话 P0（本阶段新增）

**链路**：`script_gen.generate_dialogue(article)` → `tts.synthesize_dialogue(turns, voice_map)`（每轮独立音色 + 重编码拼接治 mp3-as-wav 时长 bug）→ `text_motion.render_text_motion(..., speaker_b_color, speaker_labels)`。

**双色区分（方案 A，已落地）**：A=老六（激情男声 `YunjianNeural` / 白字），B=数据君（女声 `XiaoxiaoNeural` / 蓝字 `0x5AC8FA`）；
说话人名字前缀逐块静态首屏即显（"老六" / "数据君"），B 仅在该角色出现时追加 `BodyB/HLB/NumB` 样式组，单人口播字节级不变。

**配套改动**：
- `prompts/video_dialogue.txt`：双人口播稿 prompt（A 抛观点情绪 / B 补数据反驳，强钩子开头、严格 4–6 轮、B 禁编数字）。
- `script_gen.py`：`generate_dialogue` + 校验（`spk∈{A,B}`、A 开头、严格交替、2–8 轮、非法回退规则稿）+ `condense_dialogue_fallback`。
- `tts.py`：`synthesize_dialogue`（双音色 + `filter_complex` 重编码拼接 + 词轴/段流合并 + 位移 SRT；返回 `dialogue_segments` 带 speaker）。
- `pipeline.py`：`dialogue.enabled` 分支，meta 记录 `dialogue_used` / `dialogue_speakers` / `used_voices`。

## ⚠️ 本阶段关键 bug（已修复，带回归测试）

**B 样式组位置错误 → 双色区分失效**：`build_motion_ass` 把 `BodyB/HLB/NumB` 用 `header.extend` 追加在了 `[Events]` 之后，落进事件区段；libass 把这些 `Style:` 行当成事件文本忽略，`\rBodyB` 回退成默认样式（白字），B 全程白、双色区分消失。
修复：B 样式组挪回 `[V4+ Styles]` 区段、`[Events]` 之前。回归测试 `test_build_motion_ass_b_styles_inside_styles_section` 锁死该约束（96 字内不该再回退）。

## v4 已解决（本次收工项）

1. **字幕跟不上语速** → 根治：TTS 单次请求 WordBoundary 落盘 `.words.json`，逐字点亮映射真实词区间；
   实测 300 发音字 **滞后 0**、偏差中位数 −0.01s、对齐 93.3%（余量为多字词中间字轻微提前，方向安全）。
2. **动效太单一** → 12 种入场随机抽（连续不重样）× 节奏 3 档（240/320/460ms）× 力度 3 档（0.8/1.0/1.25）；
   `in_anim: "random"`，`anim_seed: 0`（真随机）/ >0 可复现；`auto` 仍可回统一 pop。
3. 顺手修了 3 个 bug（均有回归测试）：slide `\move` 标签被稳态缩放污染、快语速 0.3s 最短显示
   越过下一块起点（libass 堆叠跳动）、`round` 银行家舍入词边界跳词（单字块 10ms 闪没）。
